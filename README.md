## Formato das aulas

Cinco arquiteturas em rodízio: PROCEDIMENTO (42 aulas), ERRO (36), DECISÃO (34), NÚMERO (34) e CASO
(11). Fala dimensionada a 118 palavras por minuto. Slides em número definido pelo conteúdo, cada um com
desenho próprio. Cada módulo fecha em três níveis: Decisão, Contribuição e Reconhecimento.
