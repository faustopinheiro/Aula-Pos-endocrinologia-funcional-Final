# Ícones usados nos decks

Os desenhos em `icones.json` vêm de dois conjuntos de licença MIT, copiados do pacote
Iconify correspondente (`@iconify-json/healthicons` e `@iconify-json/tabler`):

- **Health Icons** (prefixo `h:`), Resolve to Save Lives. Licença MIT:
  https://github.com/resolvetosavelives/healthicons/blob/main/LICENSE
- **Tabler Icons** (prefixo `t:`), Paweł Kuna. Licença MIT:
  https://github.com/tabler/tabler-icons/blob/master/LICENSE

As cores são trocadas pelo gerador para a paleta do curso. Nenhum outro arquivo de imagem
é usado nos decks.
